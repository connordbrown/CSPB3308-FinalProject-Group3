## Vision statement:
 Prospex is a single place to track all of your job applications and connections in order to simplify and organize your job search.

## Motivation:
 The job search process is often fragmented and spread out over many different sites and applications. We want to consolidate all of that into one place so the user can better keep track of applications, application status and connections. 

## Risks to project completion

 - Risk: project creep, having too many features.
   - Mitigation: To be strict about feature set, maintain targeted goals.
      
- Risk: no prior experience working with these team members
  - Mitigation: Weekly meetings and frequent communication through group message, trello.

- Risk: Problems getting access to job listings APIs
  - Mitigation: Enter job listings manually on MVP. Research scraping, API's and alternatives later

- Risk: Lack of experience working with tools in project stack may lead to delays.
  - Mitigation: Ensure that we are accounting for the time required to learn new tools when we set goals.
 
 ## Development method:
  Scrum with week-long sprints and weekly check-ins. 
  
  - The weekly meetings are 30 minutes on Zoom, follow this format: Standup; End-of-Sprint Demonstration; Sprint Retrospective.
  - Scrum-master rotates weekly.
  - Task tracking with Trello, columns are Product Backlog, Sprint Backlog, In Progress, Done.
  - Git workflow: Each task has its own branch, merged into 'main' through a pull request.
