## Final Project Planning: User Stories

**Effort scaled 1-3 for each story**
______________________________________________________________________________

User Story Card #1 : Application Purpose
______________________________________________________________________________
*As a 	:* user \
*I want	:* to have a central location to keep all of my job applications \
*So that :* I can consolidate and effectively manage my job search

Effort
Level	: 3

Acceptance Criteria:
- Given	: 	a job application tracker
- When 	: 	I use the application
- Then 	: 	I can see all of my job applications and their status
____________________________________________________________________________

User Story Card #2 : Profile Creation
______________________________________________________________________________
*As a 	:* user \
*I want	:* create a user profile \
*So that :* I can save and manage my job applications

Effort
Level	: 2

Acceptance Criteria:
- Given	: 	a job application tracker
- When 	: 	I log in
- Then 	: 	I can see all of my job applications and their status
____________________________________________________________________________

User Story Card #3 : Edit Job List
______________________________________________________________________________
*As a 	:* user \
*I want	:* to edit my jobs list \
*So that :* I can add and remove jobs depending on their status

Effort
Level	: 2

Acceptance Criteria:
- Given	: 	a user profile in a job application tracker
- When 	: 	I add or remove jobs
- Then 	: 	my jobs list updates to reflect the most current list
____________________________________________________________________________

User Story Card #4: Organize Job Status
______________________________________________________________________________
*As a 	:* user \
*I want	:* change the status of my job applications \
*So that :* I can prioritize my efforts and stay organized.

Effort
Level	: 1

Acceptance Criteria
- Given	: 	a job application
- When 	: 	I change its status
- Then 	: 	it moves to a different location/bin
